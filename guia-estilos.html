Paso 1: Fundamento

1. Cómo conectar el archivo estilos.css a tus páginas HTML

¿Qué hace esta línea?
La etiqueta <link rel="stylesheet" href="..."> va obligatoriamente dentro de <head>. Le indica al navegador en qué carpeta se encuentra el archivo CSS que le dará colores, fuentes y orden a la página.

¿Cómo saber qué poner en href?
Depende de la carpeta donde guardaste tu HTML. Si el HTML está en la misma carpeta que css/, usas css/estilos.css. Si tu archivo está dentro de una carpeta más profunda, usas ../ para retroceder un nivel hacia afuera. 
<!-- Si tu página está en la carpeta raíz (ejemplo: index.html o guia-estilos.html) -->
<link rel="stylesheet" href="css/estilos.css">

<!-- Si tu página está dentro de la carpeta pages (ejemplo: pages/servicios.html) -->
<link rel="stylesheet" href="../css/estilos.css">

<!-- Si tu página está dentro de pages/recepcionista (ejemplo: propietarios-listado.html) -->
<link rel="stylesheet" href="../../css/estilos.css">

<!-- Si tu página está dentro de pages/recepcionista/propietarios (ejemplo: propietarios-listado.html) -->
<link rel="stylesheet" href="../../../css/estilos.css">
Paso 2: Identidad Gráfica

2. Los colores de VetCare y cómo usarlos

¿Por qué usamos variables (:root)?
En CSS creamos "nombres" para los colores (variables) para no tener que memorizar códigos como #0b6b68. Así, si alguna vez queremos cambiar el tono de verde de toda la web, solo lo cambiamos en un lugar.
--color-principal
#0b6b68
Verde de la clínica
--color-principal-oscuro
#084c4b
Tono al pasar el ratón
--color-secundario
#f3bd55
Amarillo de acento
--color-exito
#18794e
Acciones correctas
--color-error
#b42318
Alertas y peligro
--color-fondo
#f5f8f6
Fondo suave general 
/* Ejemplo: Si quieres usar estos colores en algún estilo propio */
.mi-caja {
  background-color: var(--color-principal); /* Pinta el fondo con el verde oficial */
  color: #ffffff;                           /* Letra blanca para que contraste */
  border: 1px solid var(--color-borde);     /* Borde gris clarito */
}
Paso 3: Estructura de la Pantalla

3. El Contenedor (.contenedor)

¿Para qué sirve la clase .contenedor?
Sin esta clase, el texto y las tablas se pegarían a los bordes de la pantalla del monitor y se verían muy anchos y difíciles de leer. La clase .contenedor limita el ancho máximo a 1100 píxeles y centra todo de manera ordenada en medio de la pantalla.

Resultado visual en pantalla:

Este recuadro blanco tiene la clase .contenedor
Observa cómo tiene un ancho delimitado y está centrado automáticamente.

Código HTML identado para lograr este resultado:

<!-- Usamos .contenedor en cada sección principal de la página -->
<main class="contenedor seccion-principal">
  <p>Todo el contenido que pongas aquí quedará centrado y con márgenes limpios a los lados.</p>
</main>
Paso 4: Barra Superior

4. El Encabezado, Logotipo y Avatar de Usuario

¿Cómo funciona el encabezado?
- .encabezado: Le da fondo blanco y la línea separadora inferior.
- .encabezado__interior: Coloca el logo a la izquierda y el menú a la derecha automáticamente.
- .marca y .marca__simbolo: Dibujan el logo cuadrado verde con la letra V.
- .usuario-avatar: Dibuja el círculo verde con la letra inicial de la persona conectada.

Resultado visual en pantalla:

V VetCare
C
Camila Silva Recepcionista
Cerrar sesión

Código HTML identado para lograr este resultado:

<header class="encabezado">
  <div class="contenedor encabezado__interior">
    <!-- Logotipo de VetCare -->
    <a class="marca" href="index.html">
      <span class="marca__simbolo">V</span>
      <span class="marca__texto">VetCare</span>
    </a>

    <!-- Menú y datos del usuario conectado -->
    <div class="navegacion">
      <div class="usuario-sesion">
        <div class="usuario-avatar" title="Camila Silva">C</div>
        <div class="usuario-datos">
          <span class="usuario-nombre">Camila Silva</span>
          <span class="usuario-rol">Recepcionista</span>
        </div>
      </div>
      <nav>
        <a href="index.html">Cerrar sesión</a>
      </nav>
    </div>
  </div>
</header>
Paso 5: Jerarquía de Textos

5. Títulos y Textos Secundarios

¿Cómo organizar el encabezado de cada página?
Cada pantalla debe tener su título claro. Usamos .encabezado-pagina para agruparlo, .titulo-pagina para darle el tamaño adecuado (28 píxeles) y .texto-secundario para los subtítulos en color gris suave.

Resultado visual en pantalla:

Módulo de recepción > Propietarios

Listado de Propietarios

Busca y administra la información de contacto de los clientes de la clínica.

Código HTML identado para lograr este resultado:

<div class="encabezado-pagina">
  <p class="texto-secundario">Módulo de recepción > Propietarios</p>
  <h1 class="titulo-pagina">Listado de Propietarios</h1>
  <p class="texto-secundario">Busca y administra la información de contacto de los clientes de la clínica.</p>
</div>
Paso 6: Contenedores Visuales

6. Tarjetas (.tarjeta) y Paneles (.panel)

¿Cuál es la diferencia entre .tarjeta y .panel?
- .tarjeta: Aplica el fondo blanco, las esquinas redondeadas y la sombra suave.
- .panel: Aplica el relleno interior (padding de 24 píxeles) para que el texto o los botones no queden pegados a los bordes de la tarjeta.
Casi siempre se usan juntas: class="tarjeta panel".

Resultado visual en pantalla:

Ficha Informativa

Este contenido se encuentra protegido dentro de una tarjeta con esquinas redondeadas, fondo blanco y sombra suave.

Código HTML identado para lograr este resultado:

<div class="tarjeta panel">
  <h3>Ficha Informativa</h3>
  <p>Este contenido se encuentra protegido dentro de una tarjeta con esquinas redondeadas, fondo blanco y sombra suave.</p>
</div>
Paso 7: Acciones y Clics

7. Botones y Botoneras (.boton, .botonera)

¿Qué tipos de botones tenemos?
- .boton: El botón verde principal para guardar, enviar o confirmar.
- .boton--secundario: Botón blanco con borde gris para cancelar o volver atrás.
- .boton--peligro: Botón rojo para eliminar registros o dar de baja.
- .botonera: Una caja que agrupa varios botones en una misma fila con espacio entre ellos.

Resultado visual en pantalla:

Código HTML identado para lograr este resultado:

<div class="botonera">
  <!-- Botón principal verde -->
  <button class="boton" type="submit">Guardar propietario</button>

  <!-- Botón secundario blanco -->
  <a class="boton boton--secundario" href="listado.html">Cancelar</a>

  <!-- Botón de peligro rojo -->
  <button class="boton boton--peligro" type="button">Eliminar registro</button>
</div>
Paso 8: Entrada de Datos

8. Formularios y Campos (.formulario, .campo)

¿Cómo armar campos de formulario ordenados?
Cada dato debe ir envuelto en un <div class="campo">. Este div coloca automáticamente el <label> arriba y el <input> o <select> abajo.
Detalle especial: Si agregas el atributo estándar required, el CSS le colocará automáticamente una línea verde a la izquierda para avisarle visualmente a la persona que ese campo es obligatorio.

Resultado visual en pantalla:

Datos Personales del Cliente

Los campos con borde verde a la izquierda son obligatorios.

Código HTML identado para lograr este resultado:

<form class="tarjeta panel formulario" action="guardar.html" method="get">
  <fieldset>
    <legend class="etiqueta">Datos Personales del Cliente</legend>

    <!-- Campo de texto requerido (borde verde) -->
    <div class="campo">
      <label for="cedula">Cédula de Identidad *</label>
      <input id="cedula" name="cedula" type="text" placeholder="Ej. 0105489632" required>
    </div>

    <!-- Campo de selección desplegable -->
    <div class="campo">
      <label for="tipo">Especie de la Mascota *</label>
      <select id="tipo" name="tipo" required>
        <option value="">Seleccione una especie...</option>
        <option value="perro">Canino (Perro)</option>
        <option value="gato">Felino (Gato)</option>
      </select>
    </div>

    <!-- Campo de texto multilínea -->
    <div class="campo">
      <label for="observacion">Observaciones o Síntomas</label>
      <textarea id="observacion" name="observacion" placeholder="Escribe aquí los motivos de la consulta médica..."></textarea>
    </div>

    <p class="texto-secundario">Los campos con borde verde a la izquierda son obligatorios.</p>
  </fieldset>

  <!-- Botones de acción del formulario -->
  <div class="botonera">
    <button class="boton" type="submit">Registrar Paciente</button>
    <button class="boton boton--secundario" type="reset">Limpiar Campos</button>
  </div>
</form>
Paso 9: Mensajes al Usuario

9. Mensajes de Aviso y Alertas (.mensaje)

¿Cuándo usar cada tipo de mensaje?
- .mensaje--exito: Fondo verde claro con texto verde oscuro. Se usa cuando se guardó un registro o se completó una acción correctamente.
- .mensaje--error: Fondo rojo claro con borde y texto rojo. Se usa para advertencias importantes, errores o confirmaciones de eliminación.

Resultado visual en pantalla:

Operación realizada con éxito: El propietario fue registrado en el sistema.
Advertencia sanitaria: Al dar de baja a un propietario se debe preservar el historial médico de sus mascotas.

Código HTML identado para lograr este resultado:

<!-- Mensaje verde de éxito -->
<div class="mensaje mensaje--exito">
  Operación realizada con éxito: El propietario fue registrado en el sistema.
</div>

<!-- Mensaje rojo de advertencia o error -->
<div class="mensaje mensaje--error">
  Advertencia sanitaria: Al dar de baja a un propietario se debe preservar el historial médico de sus mascotas.
</div>
Paso 10: Datos Tabulares

10. Tablas de Registros (.tabla-contenedor, .tabla)

¿Cómo se construyen las tablas en VetCare?
1. Envuelves la tabla dentro de <div class="tabla-contenedor">. Esto garantiza que si la tabla tiene muchas columnas, aparezca una barra de desplazamiento horizontal suave sin deformar la pantalla.
2. Le pones la clase .tabla a la etiqueta <table>. El CSS le dará fondo verde claro a los encabezados (<th>) y alternará las filas con un tono gris suave para facilitar la lectura.

Resultado visual en pantalla:

10:15 Rocky (Pastor) Carlos Alberto Mendoza Consulta preventiva Ver | Atender

<div class="tabla-contenedor">

Paso 11: Detalles de Registros

11. Fichas de Datos en Bloque (.datos)

¿Cuándo usar la lista de datos (.datos)?
En HTML existe la etiqueta <dl> (lista de descripción), donde <dt> es el título y <dd> es el valor. Con nuestra clase .datos, cada pareja de título y valor se convierte en una cajita gris muy limpia, ideal para páginas como "Detalle del Propietario" o "Confirmar Eliminación".

<dl class="datos">

    <dd>0105489632</dd>

Paso 12: Columnas y Distribución

12. Cuadrículas Flexibles (.cuadricula, .cuadricula--tres)

¿Cómo poner elementos lado a lado sin complicaciones?
En lugar de calcular anchos difíciles, usamos .cuadricula combinado con:
- .cuadricula--dos: Para formularios de dos columnas.
- .cuadricula--tres: Para menús o catálogos de tres tarjetas por fila. Los elementos se distribuyen con espacio uniforme entre ellos.

Resultado visual en pantalla:

1. Propietarios

Registrar y consultar datos de contacto.

2. Mascotas

Expediente clínico de los animales.

3. Servicios

Tarifas y atenciones disponibles.

Código HTML identado para lograr este resultado:

<div class="cuadricula cuadricula--tres">
  <div class="tarjeta panel">
    <h3>1. Propietarios</h3>
    <p>Registrar y consultar datos de contacto.</p>
  </div>
  <div class="tarjeta panel">
    <h3>2. Mascotas</h3>
    <p>Expediente clínico de los animales.</p>
  </div>
  <div class="tarjeta panel">
    <h3>3. Servicios</h3>
    <p>Tarifas y atenciones disponibles.</p>
  </div>
</div>
Paso 13: Búsqueda

13. Buscador Integrado (.buscador)

¿Cómo funciona la clase .buscador?
La clase .buscador alinea perfectamente la caja de texto con el botón "Buscar", haciendo que el input ocupe la mayor parte del espacio disponible y el botón quede a su lado a la misma altura.

Resultado visual en pantalla:

Código HTML identado para lograr este resultado:

<form class="buscador espacio-abajo" action="propietarios-listado.html" method="get">
  <div class="campo">
    <label for="buscar-cliente">Buscar propietario</label>
    <input id="buscar-cliente" name="q" type="search" placeholder="Escribe cédula, nombre, teléfono o correo...">
  </div>
  <button class="boton" type="submit">Buscar</button>
</form>

14. Etiquetas de Estado (.estado)

¿Para qué sirve la clase .estado?
Es una pequeña pastilla verde redondeada que se usa para mostrar estados como "Módulo activo", "Atendido" o "Confirmado" de manera muy visual en menús o tablas.

Resultado visual en pantalla:

Módulo activo

Código HTML identado para lograr este resultado:

<span class="estado">Módulo activo</span>
Paso 15: Separaciones y Cierre

15. Clases de Espaciado y Pie de Página (.pie)

¿Cómo separar secciones sin escribir nuevo CSS?
- .espacio-arriba: Agrega un margen de 18 píxeles arriba del elemento.
- .espacio-abajo: Agrega un margen de 18 píxeles debajo del elemento.
- .pie: Aplica al pie de página un tono gris suave, tamaño adecuado y separación visual con el contenido superior.

Resultado visual en pantalla:

Bloque superior
Bloque con la clase .espacio-arriba (separado automáticamente 18px del bloque anterior).
VetCare · Clínica Veterinaria Huellitas

Código HTML identado para lograr este resultado:

<!-- Separar una sección de la anterior -->
<div class="espacio-arriba">
  <p>Este bloque tiene espacio extra arriba.</p>
</div>

<!-- Pie de página estándar al final de cada HTML -->
<footer class="contenedor pie">
  VetCare · Clínica Veterinaria Huellitas
</footer>
